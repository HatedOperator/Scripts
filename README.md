# Indicator Studios

Studio site for indicatorstudios.cc. Static front-end served by a tiny Node server (server.js), deployed to GoDaddy Node.js hosting from this branch.

- \`index.html\` / \`style.css\` / \`script.js\` — the site
- \`server.js\` — serves the static files (\`npm start\` / \`npm run dev\`)
- \`images/\` — game art, group emblem, executive avatars
